Laboratory Work 5 - Indexes and Stored Procedures in MS SQL

Topic: Indexes and stored procedures in Microsoft SQL Server.
Goal: Become familiar with indexes in Microsoft SQL Server: their purpose, usage and effect on query
performance; learn the statements for creating, reorganising and dropping indexes; gain practical
skills in creating, optimising and analysing the efficiency of indexes in a database. Practise
writing stored procedures.

Task:
1. Take the test and add a screenshot with the score to the report.
2. For your main variant (the one used in practical works 3, 4, 5 and 6), add the description of the
   subject area and the logical and physical models (from practical work 5). Run the queries in any
   convenient environment (Docker, virtual machine, file database or local MS SQL instance).
3. Add the following indexes to the tables of your variant: a non-clustered index, a clustered
   index, a unique index, an index with included columns, and a filtered index. Add to the report:
   screenshots of the queries and results; a table comparing execution with and without indexes;
   save the code in QUERY.SQL.
4. Analyse your tables filled with 500, 1000 and 10,000 rows. Use at least 3 queries of your own
   choice from your variant. Present the result in a summary table and analyse the index types and
   their use depending on the number of rows.
5. Audit all indexes in the database: determine the number, type, uniqueness and fragmentation of
   each. Present a table with: index name, index type (clustered, non-clustered, etc.), uniqueness,
   fragmentation level, table the index belongs to, number of pages used by the index.
6. Write a T-SQL script using system stored procedures: make a selection with 3 procedures, add
   their specification and describe how they can be used in your database.
7. Write a T-SQL script using global temporary stored procedures: 3 procedures, with specification
   and description of their use in your database.
8. Write a T-SQL script using temporary stored procedures: 3 procedures, with specification and
   description of their use in your database.
9. Write a T-SQL script using user-defined stored procedures (the tasks from the Transactions
   part), with specification and description.
10. Write a T-SQL script that inserts into a table the number of rows given by a parameter.
11. For a table whose primary key is generated by a sequence, create a function/procedure that
    takes the values of all fields except the primary key as parameters, obtains a new primary key
    from the sequence, inserts a new record with that key and the given values, and returns the
    primary key of the inserted record, or NULL if the record was not inserted.
    (For tasks 6-11: add screenshots of the queries and results; save the code in PROCEDURES.SQL.)
12. Provide the T-SQL scripts SETUP.SQL, INSERT.SQL, UPDATE.SQL, QUERY.SQL, FUNCTIONS.SQL and a
    README describing the use of the procedures with a short explanation of the completed tasks.
13. Add conclusions and finalise the report.

Notes: Subject area of the variant: Farm. Tools: MS SQL Server.
