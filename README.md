# University labs

Lab work and small study projects from my university courses, collected in one place.
These are learning exercises, not production code. My larger projects live in separate repositories:
[svit-go](https://github.com/danylokiri/svit-go), [volunteer-hub](https://github.com/danylokiri/volunteer-hub), [bookworm](https://github.com/danylokiri/bookworm), [diploma-registry](https://github.com/danylokiri/diploma-registry).

Labs are grouped by semester and numbered (`lab-N`, `practical-N`, `coursework`, `exam`). Most lab folders contain a `TASK.txt` with the assignment translated into English. Where the original text was only available as part of a finished report or as images, the statement was reconstructed from it and this is noted in the file.

Large sample datasets, reports and build artifacts are not included.
