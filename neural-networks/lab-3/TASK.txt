Neural Networks, Lab 3: Error Backpropagation Algorithm

Topic: Training feed-forward multilayer neural networks with the error backpropagation algorithm.
Goal: Study the error backpropagation algorithm; learn to program it for training feed-forward multilayer neural networks.

Task:
1. Implement the error backpropagation algorithm in software. Set the initial values of the weight coefficients randomly.
2. Train an artificial neural network (structure and activation function are given in the variant) with the backpropagation algorithm for the given input and output vectors.
3. After the algorithm has run, output the matrices of weight coefficients and the achieved value of the error.
4. For the first input-output pair compute by hand one step of the algorithm (forward and backward pass with the sigmoid activation function). Choose the weights randomly within the given limits.
5. Prepare a report: problem statement, code listing, training result, hand calculation.

Notes: Network structure 3-2-3-1 (3 inputs, hidden layers of 2 and 3 neurons, 1 output); activation function: hyperbolic tangent. Input vectors: [0.5, 0.8, 0.05], [0.2, 0.9, 0.1], [0.8, 0.8, 0.5]; corresponding target outputs: [0.45], [0.9], [0.4]. Initial weights are random in [-1, 1]; learning rate 0.25.
