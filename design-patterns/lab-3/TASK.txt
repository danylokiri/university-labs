Lab 3 - Spring Boot CLI: command processing through the console; Maven

Topic: Spring Boot CLI, handling commands through the console, Maven
Goal: Learn to work with Spring Boot CLI and Maven commands.

Task:
1. Install Spring Boot CLI: download the archive, unpack it and add its bin directory to the PATH environment variable so that the spring command works from any directory. Check that it works.
2. Use Spring Boot CLI to create a project that can be built into a jar file (use a CLI version that supports this; make sure JDK 17 is installed, as required by the generated project).
3. Install Maven, add it to PATH and verify it with mvn -v.
4. Build the project with the Maven lifecycle commands: mvn clean, mvn verify, mvn package.
5. Run the project with mvn spring-boot:run (resolve any conflicts, such as a second class with a main Application entry point).
6. Add a new dependency to pom.xml (Lombok was used) and use it in the code: the result of the power calculation from Lab 1 is passed to a PowerResult object whose getters/constructors are generated by Lombok annotations. Rebuild (mvn package) and run (mvn spring-boot:run).
7. Answer the control questions (what Maven is and what pom.xml does; what an artifact is and how to generate it; Maven lifecycle phases: validate, compile, test, package, verify, install, deploy; how to add a dependency; what Spring Boot CLI is, how to create a project with it (spring init) and run an application (spring run / mvn spring-boot:run)).

Notes: Builds on the project from Lab 1. The task statement in the source report is implicit; the list above is reconstructed from the stated goal and the required stages of work.
