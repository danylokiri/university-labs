**Вступ (завдання, мета)**

Лабораторна робота номер 3 присвячена розв'язанню нелінійних рівнянь методами відсікання відрізків. Завдання полягає у знаходженні значень змінних для рівняння третього степеня, що описує заміну рухомого складу залізничної інфраструктури на сучасні зразки. Метою роботи є розробка та реалізація програми, що використовує три методи відсікання для знаходження коренів: метод дихотомії, метод золотого перетину, та метод Фібоначчі, з точністю до ε = 10⁻⁴.

**Що таке метод відсікання відрізків?**

Метод відсікання відрізків — це чисельний підхід до знаходження коренів нелінійного рівняння, заснований на поступовому звуженні інтервалу, в якому знаходиться корінь, доки ширина інтервалу не стане меншою за задану точність ε. До таких методів належать метод дихотомії (бісекції), метод золотого перетину, а також метод Фібоначчі.

- **Метод дихотомії (бісекції)**: цей метод базується на поділі інтервалу навпіл і виборі підінтервалу, в якому функція змінює знак, тобто корінь знаходиться в цьому підінтервалі. Процес повторюється, поки ширина інтервалу не стане меншою за задану точність ε.

- **Метод золотого перетину**: цей метод використовує принцип золотого перетину для поділу інтервалу таким чином, щоб зменшити кількість обчислень функції, наближаючись до кореня. Інтервал ділиться у пропорції, яка мінімізує максимальну довжину інтервалу на наступному кроці.

- **Метод Фібоначчі**: цей метод подібний до методу золотого перетину, але використовує числа Фібоначчі для обчислення оптимальних точок поділу інтервалу. Це дозволяє отримати високоточні результати при мінімальній кількості ітерацій.

**Реалізація програми**

Програма написана на мові Java. Вона включає три методи: метод дихотомії, метод золотого перетину та метод Фібоначчі для знаходження коренів рівняння третього степеня. Вона підтримує введення початкових даних через екранну форму або завантаження з файлу, реагуючи на можливі помилки користувача.

**Метод відсікання відрізків в програмі**

У програмі реалізовано три методи:

1. **Метод дихотомії**: поступове звуження інтервалу шляхом обчислення середини та аналізу знаків функції в отриманих підінтервалах.
2. **Метод золотого перетину**: використання коефіцієнта золотого перетину для оптимального поділу інтервалу та швидкого зближення до кореня.
3. **Метод Фібоначчі**: базується на числах Фібоначчі для поступового зменшення розмірів інтервалу, що дозволяє досягти високої точності при мінімальній кількості ітерацій.

**Введення даних в програмі**

Користувач має можливість вибрати спосіб введення початкових даних: через консоль або шляхом завантаження файлу. Програма передбачає валідацію введених даних та повідомлення про помилки, що дозволяє запобігти введенню некоректної інформації.

**Опис обчислень, що виконує програма**

Програма проводить обчислення функції виду f(x) = x³ - 4,1x² + 2,2x + 1,4. Для кожного методу програма виконує ітераційні розрахунки, поступово зменшуючи розмір інтервалу до тих пір, поки не буде досягнуто задану точність. У результаті кожен метод повертає значення кореня, яке задовольняє умови рівняння з точністю до ε = 10⁻⁴.
