Numerical Methods, Lab 3: Solving a Nonlinear Equation by Interval-Reduction Methods

Topic: Dichotomy (bisection), golden section and Fibonacci methods.
Goal: Develop and implement a program that finds the roots of a nonlinear equation using three interval-reduction methods (dichotomy, golden section, Fibonacci) with accuracy epsilon = 10^-4.

Task:
1. Problem statement: in a report on the development of railway infrastructure it was found that replacing obsolete rolling stock with modern units has a significant effect on the industry and is described by the expression
     x^3 - 4.1x^2 + 2.2x + 1.4 = 0
   Find the values of the variable that satisfy this equation with accuracy epsilon = 10^-4.
2. Solve the problem by hand with the dichotomy method.
3. Implement in a program:
   - the dichotomy method (halve the interval and keep the half where the function changes sign);
   - the golden section method;
   - the Fibonacci method (golden-section principle with fewer function evaluations).
4. Allow the interval ends and the accuracy to be entered from the console or read from a file; validate the input.

Notes: The search interval [a, b] is supplied by the user (the program uses [-5, 7] by default).
